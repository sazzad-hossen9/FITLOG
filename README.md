# FitLog

A dark, no-nonsense gym companion built with Next.js — pick a lift, add it to today's plan, and track your progress.

## Technologies Used

Next.js (App Router), React, Tailwind CSS, Lucide React, React Toastify, Context API

## Features

1. Browse a responsive workout library with category tags, equipment, and stats.
2. View detailed workout pages with specs and step-by-step instructions.
3. Add exercises to Today's Plan or Saved, with duplicate prevention and toast alerts.
4. My Plan dashboard with live stats, tabs, and sorting by duration/calories/rating.
5. Mark exercises as done or remove them anytime.
6. Plan/saved data persists across reloads via localStorage.

## Getting Started

\`\`\`bash
npm install
npm run dev
